# Coding Guidelines
- If writing golang, look at @golang-style.md
- If writing python, look at @python-style.md
- Working code is the first goal, minimizing complexity is the second goal but just as important
- Classes should be deep, interfaces should be narrow
- Whenever adding code, make sure corresponding tests exist
- Comments should describe things that are not obvious from reading the code

# General
- NEVER use em dashes
- NEVER commit credentials or .env files or similar. Use a .gitignore to exclude sensitive files
- NEVER add "co-authored by AI" to commit messages
